## Reading the evidence

These are educational exercises, not claims of production deployments, real-world compromise, or professional certifications. The walkthrough videos are hosted on Google Drive rather than committed as large Git binaries; viewer access depends on Drive sharing settings. No executable payloads are included.

**Use security tools only on systems you own or have explicit permission to assess.**

> This portfolio is intentionally housed in the GitHub profile repository under `portfolio/`. The labs can be moved into dedicated repositories later without changing the evidence claims.
