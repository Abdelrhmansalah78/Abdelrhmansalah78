# Windows System Hacking Lab — Metasploit / Meterpreter

**Type:** controlled educational virtual-machine lab  
**Tools:** Kali Linux, Windows VM, VirtualBox, Metasploit Framework, Meterpreter

## Goal

Demonstrate the connection between a Metasploit reverse TCP handler and a test payload executed within a lab Windows virtual machine.

## What the video shows

1. Windows and Kali virtual machines configured within a lab and basic connectivity checks.
2. Reverse TCP payload/handler setup within Metasploit.
3. Execution of a test file on the Windows VM.
4. A Meterpreter session opening on the Kali machine.
5. Remote file-system navigation through the established session.

## Scope and limitations

- This illustrates an educational payload/handler workflow; the video **does not establish exploitation of a software vulnerability**.
- A session does **not** establish privilege escalation, SYSTEM-level privileges, antivirus bypass, or compromise of a real-world endpoint.
- No payload executable, password, target-specific exploitation instructions, or binary sample is included in this repository.

**Educational use only, on systems owned or explicitly authorized for testing.**
